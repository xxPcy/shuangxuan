🎓 高校导师指标分配与双选系统 (WeChat Mini Program)
📖 项目简介
本项目是一个基于微信原生小程序 + 微信云开发 (Serverless) 构建的高校导师招生指标分配与师生双选系统。
系统旨在解决高校研究生/本科生招生过程中，名额分配繁琐、师生双选信息不同步、以及极易出现超额录取或并发抢报等痛点。通过完善的权限分级、并发锁机制和自动化定时任务，实现了招生全生命周期的数字化管理。

🌟 核心功能与角色划分
系统主要分为三个端（角色）：

👨‍💻 1. 管理员端 (后台统筹)
模板与数据导入：支持通过导入 Excel 文件（借助 node-xlsx 且内置严格的空行/脏数据过滤）一键初始化录入【逻辑字典表】、【导师库】和【学生库】。
多级指标分配：支持面向导师精准下发/统筹 一级、二级、三级专业代码及不同学制（如全日制/非全日制/联培/士兵等）的招生指标。
公告管理系统：支持发布精细化公告，可精准面向“全体人员”、“仅限导师”或“仅限学生”进行定向广播。
系统安全管控：内置“清空系统”功能，一键安全重置学生、导师和逻辑库，且确保系统底层多层级指标大表 (TotalQuota) 结构不被破坏。
👨‍🏫 2. 导师端 (指标与生源管理)
指标接收与确认：管理员下发指标后，导师可进行“接受”或“拒收”操作（自带高并发原子锁，防止连点导致名额翻倍）。
超时自动退回机制：对于滞留长达 48 小时未处理下发指标，系统定时器自动无感收回重置至总池，并生成拒收记录。
双选审批：查看正在申请自己名额的学生列表。若导师点击“同意接收”，系统原子级校验扣减指标容量，防止同一秒内多设备操作产生超录。
👨‍🎓 3. 学生端 (志愿双选)
智能导师筛选：依据学生自身的【报考专业（代码级别向下兼容）】与【学制类型】，自动过滤并仅展示符合名额条件且指标未满的导师。
防撞车志愿填报：学生发起导师申请后，状态即时封锁（Optimistic UI + DB 原子锁），彻底杜绝双设备登录下同时填报多名导师产生的状态错乱问题。
🛠 技术栈与架构核心
前端技术:

原生微信小程序框架 (WXML / WXSS / JavaScript)
响应式页面渲染与组件化管理。
后端技术 (微信云托管 CloudBase):

Node.js 环境运行所有云函数。
微信云开发 SDK (wx-server-sdk) 数据库交互、存储管理。
**触发器 (Cron Jobs)**实现自动化巡检与调度。
🔥 亮点技术攻坚:

防爆破并发锁 (Atomic Lock Update)：利用云数据库 db.command 进行带前置状态校验的更新操作。彻底解决了双设备极限并发导致的“一号多录”、“名额负数”、“指标翻倍”等毁灭性业务 Bug。
三级代码自动向下兼容：系统指标层级树 (level1_quota / level2_quota / level3_quota) 动态匹配逻辑。
幽灵空行净化算法：自研 Excel 解析预处理算法，过滤底层遗留格式 (UsedRange) 导致的误拼凑查询报错。
🗄 数据库结构设计 (Collections)
系统搭载微信 NoSQL 云数据库，核心集合如下：

Logic：系统业务控制逻辑与专业字典配置。
Stu：学生信息与双选跟踪状态 ( chosing / pending / chosed )。
Teacher：导师基本档案、quota_settings (多级指标池与额度追踪)。
TotalQuota：全局指标动态缓冲大池。
QuotaHolders：各专业下属指标责任人详情清单。
RejectedQuota：死信与退回日志库（记录各类超期、手动拒收的指标行为）。
Announcements：图文公告库。
🚀 部署与运行指引
1. 环境准备
下载并安装最新版 微信开发者工具。
在系统根目录里的 project.config.json 里填入个人的/团队的 小程序 AppID。
开通微信“云开发”环境，并在 app.js 或云函数初始化处指定好自己的环境 ID (envID)。
2. 云函数部署 (重要)
展开项目中的 cloudfunctions 文件夹，右键逐一点击**「上传并部署：云端安装依赖」**：

parseExcel (Excel 数据处理核心节点)
clearSystem (系统管理节点)
autoApprove (定时自动化节点) ⚠️ 必做：不仅要部署此函数，还要右键该文件夹选择「上传触发器」，使 48 小时超时巡检定时跑起来！
(等等其他你的现有云函数...)
3. 数据初始化
使用管理员端进入小程序。
在后台依次导入：Logic表 -> 导师
模板表->学生表`。
3. 开始进行指标统筹规划。
